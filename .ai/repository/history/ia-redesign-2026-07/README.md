Immutable evidence of the `.ai` information-architecture redesign of July 2026.

**Immutability boundary.** This package is provisional and reviewable while its
migration PR is open. It becomes immutable when the migration PR merges. After
merge it must not be edited, repaired, refreshed, or reconciled with later
repository state; later clarification or correction is appended through a new,
explicitly related historical record. Forward pointers are true as of the
migration and are expected to stale without repair.

**Authority.** Evidence, never authority. Never current methodology; never
loaded by any bootstrap; excluded from required-artifact discovery; nothing
under `legacy/` is an instruction source, an executable prompt, or a link
target for current documents. Repository-wide searches must treat matches here
as non-current evidence.
